# Construction Site Progress & Material Tracking System

A centralized web system to track daily site progress, register construction sites with map location, log material usage, monitor remaining stock, and provide dashboard analytics.

## Tech Stack
- Frontend: React (Vite), Tailwind CSS, React Router, Axios, Leaflet, Recharts
- Backend: NestJS, PostgreSQL/Supabase, JWT, TypeORM
- Root setup complete. See `frontend` and `backend` directories for specific setups.

## Initialization
- `npm run dev` in `frontend` for Vite dev server.
- `npm run start:dev` in `backend` for Nest API.
